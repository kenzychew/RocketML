RocketML -- sentiment demo

TF-IDF + LogisticRegression sentiment classifier, trained on IMDB reviews.

This isn't the interesting part. It's a small model, and the box below just proves the serving API underneath it responds correctly. The actual project is the pipeline that builds and ships it: CI on every push, GHCR image publishing, a hand-written Helm chart, Kubernetes deployment, and Prometheus/Grafana monitoring. See the repo for the architecture, or the Actions history for real CI runs, not a claim.
